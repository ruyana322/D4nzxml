Panduan Penggunaan

📁 Cara Pakai – Upload & Patch (TikTok)
1
Pasang Extension
Buka Chrome → chrome://extensions/
Aktifkan Developer Mode (pojok kanan atas), klik Load unpacked, pilih folder extension ini.
2
Buka Extension
Klik icon D4nzxml di toolbar Chrome. App otomatis terbuka di tab baru full screen.
3
Pilih File Video
Di tab Home, klik tombol Pilih Video lalu pilih file MP4 dari perangkat kamu.
4
Process & Download
Tekan PROCESS & DOWNLOAD. File akan diproses dan otomatis terunduh.
Output: namafile_clean.mp4
5
Upload ke TikTok Studio
Buka tiktok.com/upload atau TikTok Studio, lalu upload file _clean.mp4 hasilnya.
⚡ Cara Pakai – Termux Render Tool
1
Install Termux
Download Termux dari F-Droid (bukan Play Store). Jalankan update paket:
pkg update && pkg upgrade
2
Install Dependensi
Install paket yang diperlukan:
pkg install ffmpeg
3
Izin Akses Storage
Beri izin Termux akses file:
termux-setup-storage
Ketuk Allow saat diminta.
4
Generate Command
Buka tab Termux di app ini, isi path folder, nama file video, pilih target FPS, lalu tekan GENERATE COMMAND.
5
Salin & Jalankan
Tekan COPY COMMAND, buka Termux, paste dan Enter. Tunggu proses selesai, file output otomatis tersimpan di folder yang sama.
6
Upload Langsung + Patch
Setelah render Termux selesai, balik ke tab Home extension ini → pilih file hasil render → tekan PROCESS & DOWNLOAD untuk patch otomatis sebelum upload TikTok.
✅ Tips Terbaik

Gunakan file MP4 codec H.264 untuk kompatibilitas terbaik. Untuk TikTok, 60FPS sudah optimal — 120/240FPS cocok untuk konten slow-motion.

⚠️ Perhatian

Jika muncul error "Format tidak didukung" di proses patch, pastikan file adalah MP4 valid (H.264/AVC). Encode ulang dulu dengan Termux Render Tool jika perlu.
